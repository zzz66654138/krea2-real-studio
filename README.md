# Krea2 / Anima 真人图像工作台

一个跑在本机的 ComfyUI 前端，把「随机抽词出图」和几个常用图像工具放在一个页面里。
纯本地运行，不联网、不上传任何数据。

## 功能

| 功能 | 说明 |
|---|---|
| **直接画图** | **纯提示词出图，没有任何随机项** —— 你写什么就画什么，适合画池子覆盖不到的东西，也适合验证自己的提示词写法 |
| **真人随机生图** | 从多个提示词桶（人物/身材/服装/姿势/场景/光线）里**随机抽取**组合成提示词出图 |
| **多选白名单** | 每个桶可以**多选**若干条目，生成时**只在你选中的范围里抽**（不是全池随机） |
| **抽词明细** | 出图后完整展示**这一次实际抽到了什么**，可核对、可复用 |
| **提示词复用** | 用当前抽到的提示词再出几张，不必重新抽 |
| **多 LoRA 串联** | 最多 8 个 LoRA 按顺序串联，每个可单独设强度；内置常见 LoRA 的说明与推荐强度 |
| **参数预设** | 步数 / CFG / 采样器 / 调度器组合，含 Krea2 Turbo 的常用配方 |
| **骨架生成** | 生成 OpenPose 骨架图 |
| **图变高清** | 走放大模型 + 原尺寸精修两段 |
| **图解析 Tag** | 反推图片的提示词标签 |
| **任务可停** | 生成中途可取消，已出的图不会丢 |

## 环境要求

- Windows + Python 3.11+
- 已装好并可运行的 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)
- 建议显存 ≥ 12 GB（12B 级模型在 16 GB 卡上可跑，出图约 1 分钟/张 @1.5MP）

## 快速开始

```bat
:: 1) 启动 ComfyUI（先确认它自己能出图）
:: 2) 启动本工具
启动界面B.bat
```

然后浏览器打开 <http://127.0.0.1:8191>。

脚本会自动寻找 `venv\Scripts\python.exe` 或 PATH 里的 `python`。
如果没找到，编辑 `启动界面B.bat` 里的 `PY` 变量指向你的解释器。

## 配置

| 配置项 | 方式 | 默认 |
|---|---|---|
| ComfyUI 地址 | `--comfy-url` | `http://127.0.0.1:8188` |
| 监听端口 | `--port` | `8191` |
| **ComfyUI 输出目录** | `--comfy-output` 或环境变量 `COMFY_OUTPUT` | 自动探测常见路径 |

```bat
python run.py --port 8191 --comfy-url http://127.0.0.1:8188 --comfy-output "D:\ComfyUI\output"
```

输出目录用于「产物目录」入口和文件管理。找不到时相关功能会**降级并明确提示**，不影响出图。

## 产物目录

输出按**日期**自动分目录：

```
<ComfyUI 输出目录>\studioB\
├── real\<日期>\<日期>_<序号>.png      真人随机生图
├── pose\<日期>\...                    骨架生成
├── upscale\<日期>\...                 图变高清
├── tags\<日期>\...                    图解析 Tag
└── _test\<日期>\...                   测试产物（可整目录删）
```

## 提示词数据

`real_pools.json` 是**提示词桶**数据，`real_characters.json` 是角色名表。
两个都是**纯 JSON，可以直接编辑**，不写代码就能扩充自己的池子。

## LoRA

把 `.safetensors` 放进 ComfyUI 的 `models/loras/`，重启 ComfyUI 后即可在界面下拉里选到。
界面内置的 LoRA 说明来自 `run.py` 的 `LORA_PRESETS`，可自行增删。

> **注意**：LoRA 分属不同模型族（krea2 / anima / …），**跨族使用通常无效**，
> 界面会在跨族时给出警告。串联多个「身份类」LoRA 会互相串味，建议一次只加一个。

## 内容说明

本工具输出**写实人物**图像，面向成年用户。内置的服装品类包含泳装、内衣、丝袜等，
用于生成成年人物的写实造型；代码内置**未成年人保护检查**（未成年人分类下会强制
排除成人向服装与身材描述），该检查不可通过界面关闭。

使用者需自行确保生成内容符合所在地法律法规，以及所使用模型与 LoRA 的许可条款。
