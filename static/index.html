模式

按系列分组，可以勾多个角色 —— 每张图从勾选的角色里抽一个。 用 Danbooru 格式的角色名（如 furina (genshin impact)），Krea2 认这个格式。
⚠️ 实测提醒：coser 措辞偶尔会画出「coser + 角色」两个人，负面里已加「双人 / 多个人」压制。

服装 真人版的特色

具体衣服在哪里：每个槽下面默认就展开了条目列表（按类别分组）， 直接勾选即可；一条不勾 = 该槽全部随机。想收起来点「收起 ▴」，或点槽名那一行也能开合。

场景 / 人物 / 动作 每槽都可多选

勾几条就只从那几条里抽；一条不勾 = 全部随机； 「不写」= 完全不参与提示词。这六项原本永远是随机的，连 API 都改不了。

镜头 成套使用，保证人物清晰

景别 / 距离 / 焦段互相绑定，负面会跟着景别自动加（如选全身就压制「半身照、裁切到脚部」）。 不提供「浅景深 / 背景虚化」当随机项 —— 那是人物模糊的主要来源。

参数

选择 LoRA 后会显示它是什么、推荐强度和触发词。 注意这批 LoRA 分属 4 个模型族，跨族使用大概率无效。
多个 LoRA 是依次串联叠加：风格类叠加安全；身份/角色类叠加 会互相串味（身份互相渗透），要空间隔离得用社区的区域掩码节点。 每行的数字是 LoRA 强度。原先还有个 LoRA→CLIP 输入，已删除：实测我们全部 LoRA 的文本编码器侧权重都是 0 个，那个开关点不出任何效果。

两段式精修（替代被否掉的锐化）：第一段正常出图 → 放大模型 4x → 缩回 0.5（净 2x）→ 低去噪重绘 → 再解码。第二段特意用不带 LoRA 的原始模型， 避免风格被二次强化。去噪 0.15 / 4 步是参考工作流给的取值。 实测耗时尚未测，第一次用请先出 1 张看时间。

官方配方是 8 步 + 低 CFG —— Turbo 是蒸馏模型，步数或 CFG 更高都会「过熟」。
实测同种子：8步/cfg1.0 → 干净 48s；8步/cfg1.5 → 干净 75s；8步/cfg2.5 → 绿色撕裂条纹； 8步/cfg3.5 → 烧图；16步/cfg2.5 → 干净但慢约 4 倍。
cfg=1.0 时负面提示词在数学上完全失效，想用负面就得 cfg>1； 反过来「置零负面 + 高 cfg」等于把条件放大到崩坏，两者必须配对。
官方配方保存前还有一步 ImageSharpen，本机一直漏做。锐化默认关， 方便你对比它会不会破坏「光滑干净的写实」。
选了 krea2_raw_* 时参数完全不同：30–52 步 / CFG3.5（12 步未收敛会出噪点）。
