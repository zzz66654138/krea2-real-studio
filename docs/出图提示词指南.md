# 出图提示词指南（新手版）

写给第一次用 Krea2 / Anima 画图的人。

目标只有一个：**你写的东西，模型能照做。**

不需要背术语，照着抄就行。

---

## 一、3 分钟上手

1. 打开工具，点顶部 **「直接画图」**
2. 在**正向提示词**框里写你想要的东西
3. 其他都别动，直接点 **「开始画图」**
4. 第一张图大约 **25~60 秒**（看分辨率）

默认参数已经是好的：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 步数 | 8 | 够了，加了只是更慢 |
| CFG | 1.0 | 重要，见 §5 |
| 采样器 | er_sde | 别改 |
| 调度器 | sgm_uniform | 别改 |
| 百万像素 | 1.5 | 想更清晰调到 2.0，代价是更慢 |

## 二、一条好提示词长什么样

### 直接抄这个骨架

```
<谁 / 什么> + <在哪> + <在做什么>

主体：年龄、性别、外形（可看见的特征）
服装：单品 + 颜色 + 材质
动作：身体姿态、手在哪、脸朝哪
环境：地点 + 周围有什么
镜头：景别（全身/半身/特写）+ 焦段
光线：从哪个方向打来 + 暖还是冷 + 硬还是软
风格：照片 / 油画 / 电影感…
```

### 完整例子

```
一个二十七八岁的亚洲女性，侧脸，长深棕色头发，齐刘海，靠在一面墙上。
她穿一件挺括的白色短袖衬衫，右手轻轻放在脖子旁边，眼神望向左边。
背景是夜晚的街道，几台亮着的自动贩卖机把光打在墙上。
暖金色的光从左边照在她脸和肩膀上，身后的 glossy 表面反射出冷冷的青蓝色。
镜头：85mm，半身构图，浅景深，背景轻微虚化。
风格：电影感人像摄影，柔和，干净通透。
```

**这段话里没有一句是废话** —— 每一句都能在图上找到对应的东西。

## 三、三个立刻见效的改写技巧

### 技巧 1：把"感觉"换成"看得见的东西"

这是新手最大的问题。模型不认识"高级感""温柔""有气质"。

| ❌ 别写 | ✅ 改成 |
|---|---|
| 很有高级感 | 纯黑背景，哑光陶瓷质感，边缘一道细微高光 |
| 看起来很温柔 | 眉眼低垂，嘴角轻微上扬，柔光正面照，没有硬阴影 |
| 身材很好 | 锁骨明显，手腕纤细，肩窄于胯 |
| 很干净 | 皮肤通透，看不到明显瑕疵，鼻梁和颧骨有柔和过渡高光 |
| 有电影感 | 浅景深 + 背景适度虚化 + 青橙对比色调 |

**判断标准**：你写的每个词，都要能回答"**这在图上长什么样**"。答不上来就删掉。

### 技巧 2：光线一定要给方向

**一张图看起来"脏""平""假"，八成是光线没写清。**

最低限度写三件事：

```
光从【左前方 / 顶上 / 窗外】来，色温【暖 / 冷】，边缘【硬 / 柔】
```

再进阶一点，用**两组光**做对比，画面立刻有层次：

```
暖金色的主光从左前方打在脸上，背景用冷青色的环境光
```

### 技巧 3：镜头会决定构图

- 想要**全身** → 必须有**竖图**（2:3 / 3:4 / 9:16），并写 `全身构图`
- 想要**脸清晰** → 用**半身或特写**，别在远景里要求精致的脸
- 写 `85mm 浅景深` → 人物突出、背景虚化
- 写 `24mm 广角` → 环境大、人物小

> **常见事故**：用方图（1:1）却要求"全身站姿"，结果人被裁到只剩半身。
> 先选对画幅，再写景别。

## 四、出问题了怎么改

对着症状找原因，别乱改提示词：

| 你看到的 | 真正的原因 | 怎么改 |
|---|---|---|
| 人要全身，出来只有半身 | 画幅太方 / 没写景别 | 换竖图 + 写「全身构图」 |
| 脸糊、五官变形 | 脸在图上占的像素太少 | 提高分辨率，或改成半身/特写 |
| 出现了我没写的衣服 | 服装写了两套以上，或 LoRA 自带 | 服装只留一条主线 |
| 画面脏、发灰 | 光线方向互相打架 | 只留一个主光方向 |
| 画面很平、没质感 | 没写材质和高光 | 加"哑光/缎面/磨砂"+ 高光位置 |
| 人物姿势别扭 | 动作写得太抽象 | 写清重心、手在哪、身体朝向角度 |
| 越写越乱 | 信息互相稀释 | 砍到 3~4 个核心点，其余留白 |
| 换了个种子结果完全不同 | 正常现象 | 想复现必须**固定种子** |

## 五、负面提示词什么时候才有效

**这一条能帮你省掉大量白费功夫。**

| CFG | 负面提示词 | 怎么办 |
|---|---|---|
| **1.0** | **完全无效** | 写了等于没写 |
| 1.5 以上 | 生效 | 但画面会变"硬"，也更慢 |

工具默认 CFG = 1.0，所以**默认情况下负面是无效的**。

想压制某个东西，两个办法：

1. **把 CFG 调到 1.5**，然后再写负面
2. **改用正面描述间接实现**（推荐，不改变画面质地）

| 你想要的 | ❌ 负面写法（CFG=1 时无效） | ✅ 正面写法 |
|---|---|---|
| 别露出手 | 不要出现手 | 双手插在外套口袋里 |
| 别太瘦 | 太瘦了 | 身材匀称，脸颊有肉感 |
| 别有杂乱文字 | 不要文字 | 纯色背景，无任何文字和标识 |

## 六、想复现、想对比

**只改一个变量，其他全部不动**，这是唯一可靠的比较方法。

```
1. 把「种子」填成一个固定数字（比如 12345）
2. 画一张，记下来
3. 只改你怀疑的那个词，其余不变，再画一张
4. 两张对比 —— 有变化说明这个词有用，几乎一样说明它没用
```

> 种子 = 随机数的起点。**种子固定 + 参数固定 = 每次出同一张图**。

## 七、LoRA 必看（新手最容易翻车）

LoRA 是给模型装的"风格/角色补丁"。三条铁律：

### 1. 强度别用 1.0

很多 LoRA 的推荐强度是 **0.2 ~ 0.8**。用 1.0 会"烧图"：

- 边缘出现彩色条纹
- 颜色被洗掉
- 皮肤/布料的纹理溶解成脏块

**选了 LoRA 后，强度框会自动填上推荐值，别手动改成 1.0。**

### 2. 一次只挂一个

挂两个以上，尤其是"角色/身份类"的，**会互相串味** —— 变成一张混合脸。

风格类 LoRA 叠加一般安全，但也建议先一个一个试。

### 3. 跨模型族 = 无效

给 Krea2 做的 LoRA 装到 Anima 上，**基本不会生效**，甚至污染画面。
界面会给出警告，看到警告就别用。

> **怎么判断 LoRA 到底有没有生效？**
> 固定种子、固定提示词，只把 LoRA 去掉再画一张，两张对比。
> 几乎一样 = 没生效。

## 八、常见问答

**Q：写中文可以吗？**
可以。Krea2 对中文理解不错，中文直接写没问题。

**Q：要不要写 `masterpiece, best quality, 8K` 这种词？**
**不用。** 这类词对现代扩散模型基本没有作用，只是占位置。

**Q：提示词越长越好吗？**
不是。**信息密度高**才好，重复和空话是负资产。中文 100~200 字、英文 60~120 词通常就够。

**Q：为什么别人能画出某个效果，我不行？**
大概率差在**光线**和**镜头**这两句，而不是形容词。

**Q：出图很慢怎么办？**
降"百万像素"。1.5 → 1.0 大约快三分之一。步数保持 8 不要加。

**Q：同一个提示词，每次出来都不一样？**
正常。想要一样，就把种子填成固定值。

## 九、一页速查

```
【骨架】
主体 + 服装 + 动作 + 环境 + 镜头 + 光线 + 风格

【三条铁律】
1. 每个词都要能回答"这在图上是什么样"
2. 光线一定要写方向
3. 全身必须配竖图

【参数】
步数 8 · CFG 1.0 · er_sde · sgm_uniform · 1.5MP
CFG=1 时负面无效

【LoRA】
强度用推荐值（常常是 0.2~0.8，不是 1.0）
一次一个，跨族无效

【想复现】
固定种子，一次只改一个词
```

## 十、内容边界

本工具用于生成**成年人**的写实图像。

内置的未成年人保护检查（抽到未成年人类别时自动排除成人向服装与身材描述）**无法通过界面关闭**，请不要尝试绕过。

请自行确保生成内容符合你所在地的法律法规，以及所用模型与 LoRA 的许可条款。
